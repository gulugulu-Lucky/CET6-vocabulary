# CET6 Vocabulary Repository Guard

This repository is exclusively for the CET6 vocabulary web app and its vocabulary data.

## Allowed work

- CET6 vocabulary content and corrections
- vocabulary review pages
- spelling, definitions, examples, filters, progress, and study interactions
- build or deployment files strictly required by this vocabulary app

## Forbidden work

Do not create, copy, modify, or import anything related to:

- Keats' Home
- Phaser, PixiJS, game scenes, rooms, furniture, character movement, or autonomy systems
- `phaser-main-room/`
- `visual-bible/`
- `autonomous-core/`
- unrelated websites, games, documents, or experiments

## Mandatory repository check

Before modifying files, verify that the intended task is about CET6 vocabulary. If the task mentions Keats, a house, a room, a game, Phaser, PixiJS, character art, or autonomous behavior, stop immediately and report that the wrong repository is open.

Never place unrelated project files in this repository, even temporarily.
